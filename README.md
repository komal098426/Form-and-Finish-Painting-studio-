# Form and Finish Painting Studio

A modern, high-performance website for Form & Finish Painting Studio, crafted with Next.js, TypeScript, and modern CSS animations.

## Features

- **Architectural Botanical Aesthetic**: Curated color palette featuring deep emerald greens, warm travertine oat/sand tones, and honey amber accents.
- **Interactive Hero Section**: High-resolution architectural photography with responsive text framing.
- **Interactive Service Cards**: Smooth GSAP hover animations with dynamic image zooming and staggered typography reveals.
- **Project Gallery**: Categorized filtering with an interactive modal lightbox for full-screen exploration.
- **Glassmorphic Navigation**: Capsule-shaped floating header with responsive mobile drawer.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## Getting Started

First, install the dependencies:

```bash
npm install
# or
pnpm install
```

Then, run the development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Animation**: [GSAP](https://greensock.com/gsap/)
- **Icons**: [Lucide React](https://lucide.dev/)
